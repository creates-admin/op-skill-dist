# デザイン NG リスト

モック作成 (`design-mock.md`)・UI 実装 (designer-expert / feature-expert)・UI の post-check (ux-ui-audit-expert) の共通基準。
「AI が作った感じ」を出すお決まりの装飾を名前で禁止する。**新しい癖を見つけたら 1 行ずつ追記して育てる。**

## 守ること

- 見た目は対象 repo の既存 design token / component / layout で作る。repo に無い装飾を足さない。
- 階層は「サイズ・太さ・余白・配置」で表す。色・線・ラベル・記号を足して階層を作らない。
- 要件に無い要素 (セクション・ラベル・装飾・統計・CTA) を作らない。画面は要件の情報だけで構成する。
- 書体は repo の既存フォント (無ければ OS 標準のゴシック体 / sans-serif)。

## NG

| NG | 代わりに |
|---|---|
| カード・リスト項目の左端の縦アクセントバー (indicator) | 状態は既存のバッジ / アイコン / 色トークンで示す。区切りは余白か既存の border |
| 「01 / 02 / 03」等の番号ラベル | 順序に意味がある手順以外は番号を付けない。手順でも既存の stepper / 通常の数字で |
| 見出しの上の英語アイブロー (小さい大文字の英語ラベル、`FEATURES` 等) | 付けない。必要なら日本語の見出し階層で |
| 明朝体・serif 体 (見出しの装飾含む) | repo の既存フォント、無ければゴシック体 / sans-serif |
| cream / off-white / ベージュの背景 | repo の既存背景トークン |
| 見出しの一部だけをイタリック・グラデーション・別色で強調 | 強調は太さとサイズのみ |
| monospace のラベル・数字装飾 | コード・ID・数値の桁揃えが必要な表以外は本文フォント |
| pill 型 (完全な角丸) のボタン・チップ | 既存 component の角丸 |
| 紫〜青のグラデーション、glassmorphism、過剰な影・glow | 既存 token の色と影のみ |
| 見出し・箇条書き・ボタンの絵文字、✨ 等の装飾記号 | 使わない。アイコンは既存アイコンセットのみ |
| 大きな数字の stat カードの横並び、中央寄せヒーロー + CTA 2 つ | 要件に無いなら作らない |
| 装飾だけのバッジ・タグ・「NEW」ラベル | 状態を表す必要があるときだけ既存バッジで |
