# 1 つのセッションの中の並列

Issue や積み重ねの段を 2 つ以上持つときの分け方。いつセッション (スレッド) を分けるかの物差しはコーディネーター側の決まりにあり、ここには書かない。

- 触るファイルが重ならない組ごとに「波」に分ける。同じ波は Agent で同時に進め、終わったら次の波へ。
- 積み重ねの上の段は、下の段の形が決まってから次の波に入れる。
- Agent 1 体に Issue 1 件か段 1 つ。worktree とブランチは Agent ごとに分ける (`_shared/worktree-ops.md`)。
- Agent は実装とテストまで。`/code-review`・push・PR・stack・見張り・マージはセッションが行う。
- 数の上限は決めない。同じ波で重ならないものは全部並べ、レビューと PR が追いつかなくなったら波を分ける。
- Agent には Issue の本文と読むべき正本のパスだけを渡す。小さい Issue は自分でやる。レビューは PR ごとに 1 回。
- Agent ごとの進みは、チェックリストがあればその行で見せる。
- 詰まりそうなら、コーディネーターがいれば「この段を別スレッドに出して」と頼む。いなければ、この場で続けるか、分け方を人に見せて別のセッションを人に立ててもらう。
