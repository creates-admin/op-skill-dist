# op-architect フェーズ2: プロジェクト種別ごとの論点チェックリスト

全種別に共通の論点に、判定された種別の固有論点を足して論点リストにする。選択肢は論点ごとに現時点の主流から 2〜4 個に絞って提示する (フェーズ3-1)。

## 共通

1. 主言語・主 FW (種別が未確定の場合)
2. 実行環境 (デスクトップ / Web / モバイル / サーバ / CLI)
3. データ層・永続化
4. 認証
5. ロギング・観測
6. テスト戦略
7. パッケージング・配布・デプロイ

## 種別固有

| 種別 | 固有の論点 |
|---|---|
| Tauri v2 + Vue 3 | フロント FW 構成 / 状態管理 / ルーティング / Tauri command 設計 (ファイル分割粒度・命名) / OS keychain 利用 / 自動アップデート / パッケージング対象 OS |
| Vue 3 SPA / Nuxt | ベース (Nuxt か Vite + Router) / レンダリング (SPA / SSR / SSG / Hybrid) / 状態管理 / API 通信 / スタイル / フォーム検証 / デプロイ先 / i18n |
| Flutter | 状態管理 / ルーティング / HTTP / 対象プラットフォーム / デザインシステム (Material 3 / Cupertino / カスタム) / i18n / リリース経路 |
| Rust CLI / サーバ | エントリ (CLI / サーバ / 両方) / 非同期ランタイム / エラー型 / 設定 / 観測 (metrics / tracing) / 配布 (crates.io / バイナリ / Docker) |
| その他 | 共通論点のみ |
